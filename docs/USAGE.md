## 识别与确认型号

1. 拍照或上传设备图片，可以同时补充品牌、用途或已知信息。
2. 查看外观分析与候选型号，比较匹配点、差异和未确认信息。
3. 找到对应型号后选择并确认；如果都不符合，排除候选，再补充文字或按建议补拍。
4. 确认后等待资料检索与索引构建，随后开始提问。

**不必先拍到铭牌。** 整机外观、摄像头或接口布局等都可以作为线索，但外观相似的产品仍可能无法区分。系统可建议补拍背面、接口、标签或其他细节。

候选可以来自外观推测、产品资料比对，或已启用服务的以图搜图结果。它们都是待确认信息；选择候选不等于官方认证。销售地区、硬件修订也需要独立线索，不能用制造地或固件号替代。

## 理解资料状态

| 状态或现象           | 含义                                     | 可以做什么                             |
| -------------------- | ---------------------------------------- | -------------------------------------- |
| 正在检索、解析或构建 | 正在查找资料、提取正文或生成向量         | 留意当前任务附近的进度与提示           |
| 已有可用资料         | 部分资料已通过相应核验，可参与回答       | 打开引用，检查适用型号和页码           |
| 资料仍待补充         | 尚未获得足够适用资料，不代表完全无法提问 | 补充型号信息，或继续提问并查看答案依据 |
| 网络暂时限制访问     | 来源站点可能限流、拒绝访问或暂不可达     | 稍后重试；系统也会尝试其他适用来源     |
| 型号待来源核验       | 用户已选择型号，资料尚未独立证实适用性   | 补充地区、版本或清晰标签               |

资料构建优先研究官方来源；无法取得合适的官方正文时，可建立**第三方说明书补充索引**。第三方文件仍须检查实际正文、型号适用性和引用，但不会因此升级为官方来源。

普通 PDF 页面直接提字；缺少可用文字层的页面会转成图片，调用当前图像模型转写。每份说明书最多处理 **20 个扫描页**，保留原页码并缓存成功页面。超限、超时或页面不可读会明确提示；图像配置或正文变化可能需要重新识别。

## 问答与来源标识

建议直接描述目标，例如“怎么连手机？”或“播放和暂停应该怎么操作？”，并说明已经尝试过什么。

| 答案依据             | 展示方式                                    | 如何理解                                               |
| -------------------- | ------------------------------------------- | ------------------------------------------------------ |
| 已核验官方资料       | 核验资料引用                                | 可检查正文、版本和适用性                               |
| 第三方索引或实时网页 | 联网或补充资料来源，区分官方 / 第三方       | 有实际来源支撑，第三方不等于官方保证                   |
| 缺少足够资料         | **模型推测 · 未经资料核验**，列出“尚未确认” | 根据品牌、型号与问题生成参考，可能不准确，没有证据引用 |

系统优先使用已有核验资料；不足时检索第三方补充索引及实时网页。仍无法支持答案时，才生成明确标注的模型参考，不将它写成“已查阅说明书”。

有引用的回答还会检查引用是否支持动作、条件和参数。身份冲突可能触发澄清，明确危险请求会被拒绝。引用核验也依赖模型判断，重要参数与可能损坏设备的操作仍应核对原文。

历史回答保留原有依据；新版本上线不会自动重写旧答案。可重新提问或使用已有的重新搜索入口取得新结果。

## 语音和图片提问

- **图片与文字**：提问图片与问题一起发送给配置的图像服务，作为设备状况的观察线索；照片不能替代资料证据或自动证明操作成功。
- **只有图片**：系统可能先询问你希望了解什么，再继续回答。
- **录音提问**：服务可用时显示入口，录音先转成可编辑文字，由你确认并主动发送。转写本身不创建问答消息。

浏览器录音最长 60 秒，转换为 16 kHz 单声道 WAV。照片与音频会发送至所配置供应商，真实请求会消耗相应服务额度。

## 说明书、记忆与操作引导

### 说明书

说明书按版本管理，章节保留资料与页码。补充资料生成新版本，失败时不会覆盖旧可用版本；可重试未完成任务。第三方补充索引和联网答案不等同于官方说明书已完成。

个人说明书只对本人可见，将已确认且未过期的个人设置与官方正文区分展示。撤销记忆后，对应个人补充不再展示。

### 我的记忆

偏好或设置可能成为待确认候选。在“我的记忆”中确认或删除后再决定是否用于后续回答。未确认、过期或删除的内容不参与个性化；设备设置按实例隔离，只有本人全局偏好可跨本人设备使用。

### 操作引导

每次显示一个动作、前提、成功条件与核验引用。完成后反馈结果；需要澄清时不会直接推进。可以暂停并在重新打开页面后恢复当前步骤。

操作引导要求核验证据，不能把问答里的模型推测当作已核验操作步骤。高风险请求不能通过勾选确认来解除限制。

## 历史与删除

可以切换产品、查看历史会话，或删除本人的产品、会话、账号及符合清理条件的照片。

删除先屏蔽访问并取消相关私有任务，再由 Worker 分批清理记录和文件；仍被其他内容引用的照片或仍处在签名有效期内的对象可能延后清理。公共资料不会因单个用户删除产品而一并删除。

## 常见问题

| 问题                   | 建议                                                            |
| ---------------------- | --------------------------------------------------------------- |
| 候选型号都不对         | 排除候选，补拍有区分度的部位，并补充品牌或用途                  |
| 识别正确却搜不到说明书 | 设备身份和资料获取是两条链路；检查失败原因，补充地区/版本后重试 |
| 仍提示额度已用完       | 管理员需区分网站日额度和供应商余额；切换模型不会清空计数        |
| 扫描页一直失败         | 检查图像模型额度、可读性、20 页上限和超时                       |
| 回答显示模型推测       | 当前证据不足，按参考阅读；可补充设备信息再提问                  |
| 看不到管理界面         | 管理入口只对已授权管理员开放，注册不会自动授予权限              |

配置与诊断见[模型与服务配置](CONFIGURATION.md)和[运行管理](../infra/V2_RUNTIME.md)。
